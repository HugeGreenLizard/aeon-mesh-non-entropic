# 📡 PUBLISHING & COMMUNITY LAUNCH GUIDE

## 1. Step-by-Step GitHub Publishing Commands

To push your release kit (`Dla_swiata`) as a public GitHub repository, run the following commands in your terminal:

```bash
cd ~/Dla_swiata
git init
git add .
git commit -m "feat: Initial public release of ÆON MESH core and whitepaper (TRL 7)"
git branch -M main
git remote add origin https://github.com/HugeGreenLizard/PWK-Core-Architecture.git
# Or your new public repo URL:
# git remote add origin https://github.com/YOUR_USERNAME/aeon-mesh-public.git
git push -u origin main --force
```
